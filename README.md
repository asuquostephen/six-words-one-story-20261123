# Six Words, One Story — entry

Entry for the make.fun competition [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) (slug `u-deranalabs-six-words-one-story-f982e410`).

`main.py` (Python 3, standard library only) writes one complete story in exactly six words to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), verifying before it writes that the text is exactly 6 words and at most 60 characters, and that the file round-trips byte-for-byte.

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
    cat /tmp/out/entry.txt
